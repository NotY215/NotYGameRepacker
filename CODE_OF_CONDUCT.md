# Code of Conduct

## Our standard

NotY Game Repacker is intended to be a technical project where people can discuss code, documentation, bugs, architecture, and legitimate software packaging work respectfully.

Participants are expected to:

- Be respectful and constructive.
- Focus criticism on code, designs, and ideas rather than people.
- Provide useful technical context when reporting problems.
- Accept that maintainers may make different engineering decisions.
- Respect project scope and legal boundaries.
- Avoid harassment, threats, discrimination, personal attacks, or deliberately disruptive behavior.

## Unacceptable behavior

The following are not acceptable in project spaces:

- Harassment or targeted abuse.
- Threats or intimidation.
- Hate-based or discriminatory attacks.
- Publishing private personal information.
- Deliberately disrupting discussions, issues, pull requests, or project infrastructure.
- Repeatedly submitting misleading or intentionally malicious reports.
- Encouraging the project to bypass legitimate ownership, licensing, activation, or security controls.

## Enforcement

Maintainers may edit, close, hide, or remove content and may restrict participation when necessary to keep project spaces constructive and safe.

Serious or repeated violations may result in removal from project participation.

## Reporting

If you encounter behavior that violates this document, use the project's reporting channels and provide enough context for the maintainers to understand what happened.

See [REPORTING_GUIDELINES.md](REPORTING_GUIDELINES.md).

## Scope

This code of conduct applies to project discussions, issues, pull requests, documentation contributions, and other project-managed community spaces.

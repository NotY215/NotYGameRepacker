# Contributing

NotYGameRepacker is a C++20 Windows game packaging/repacking project using CMake, Qt6, Zstandard, AES-256-GCM, BLAKE3, streaming and multithreading.

## Development

Use the documented CMake presets and inspect the existing architecture before changing the .noty format, cryptography, streaming or GUI behavior.

Build and run the relevant tests before opening a pull request. Keep changes focused and document format or compatibility changes.

Do not commit generated binaries, keys, credentials, proprietary game files or unrelated assets.
